## CHAT-01 多会话多模型流式对话
- **用户故事**：作为创作者，我在多个会话间切换、随时换模型，回复逐字流式生成。
- **功能描述**：SSE 流式输出；会话级模型切换；思考过程折叠；中断/继续。
- **交互要点**：打字机效果可关；断流自动重连一次，失败保留半截消息可重试。
- **现有代码映射**：`src/hooks/useChat.ts`、`src/services/api/chat.ts`、`ChatContainer.tsx`。
- **验收**：首 token ≤2s（网络正常）；断网重连不丢已生成内容。

## CHAT-02 深度思考模式
- **用户故事**：复杂问题希望模型先推理再作答，并能看到思考链。
- **功能描述**：开关切换思考型模型/参数；思考链独立折叠区。
- **交互要点**：「深度思考」按钮在输入框工具栏；思考中显示实时摘要。
- **代码映射**：`src/types/conversation.ts` Message.thinking 已预留。
- **验收**：思考链渲染无卡顿；关闭后行为与普通模式一致。

## CHAT-03 联网搜索与引用溯源
- **用户故事**：时效性问题 AI 边想边搜，给出可点击来源。
- **功能描述**：搜索开关；检索→聚合→生成三阶段状态；引用角标悬浮预览。
- **交互要点**：来源列表附回答尾部；可跳原文。
- **技术依赖**：搜索 API BYOK（博查/Zhipu/Tavily 可配）+ 后端 readability 抓取。
- **验收**：时效性问题含 ≥2 有效引用；无 Key 提示配置入口。

## CHAT-04 图片理解输入
- **用户故事**：粘贴或拖入图片，AI 识别内容并回答。
- **功能描述**：粘贴/拖拽/选择三入口；多图混文本；视觉模型自动路由。
- **交互要点**：缩略图可放大可移除；非视觉模型选中时提示切换。
- **验收**：jpg/png/webp/heic 正常识别；10MB 图 5s 内完成上传编码。

## CHAT-05 对话内生图
- **用户故事**：对话中说「画一只橘猫」，回复直接出图且可继续改图。
- **功能描述**：意图分类命中生图→路由图像生成能力；富媒体消息呈现；追问「换成夜景」触发 I2I。
- **交互要点**：图片操作条（放大/编辑/下载/存画廊）；生成中骨架屏。
- **数据闭环**：产物写统一 Asset 模型 `source=chat` 自动进画廊（PLAT-06）。
- **验收**：生图意图召回率抽检 ≥90%；「再改一版」主体一致性可用。

## CHAT-06 对话内生视频
同 CHAT-05 路由视频生成适配器。耗时长采用异步任务卡（进度+完成后内嵌播放）。P2 / M2。

## CHAT-07 实时语音通话
- **用户故事**：像打电话一样对话，方言可识别。
- **功能描述**：MVP 用 ASR→LLM→TTS 管道串联（BYOK 友好）；全双工 RTC 远期。
- **交互要点**：全屏通话界面；说话即停播报（VAD）；方言能力随厂商标注。
- **验收**：端到端延迟 ≤3s；打断响应 ≤800ms。技术路线见 09 §7。

## CHAT-08 语音输入与 TTS 播报
按住说话转文字（ASR BYOK）；回答可选自动朗读（多音色）。P1 / M2。

## CHAT-09 提示词快捷指令
- **用户故事**：常用提示词一键复用。
- **功能描述**：「/」唤起面板；指令=名称+模板+参数槽位；从 Prompts 模块导入。
- **代码映射**：`src/pages/management/prompts/` 改造为轻量指令库。
- **验收**：创建到使用 ≤30 秒；变量占位替换可用。

## CHAT-10 消息级操作
- **用户故事**：不满意可重新生成、编辑重发、开分支。
- **功能描述**：悬停操作条：复制/重新生成/编辑重发/引用/分支新会话；分支保留父上下文快照。
- **交互要点**：编辑重发截断后续消息需二次确认；分支带「源自 xx」标记。
- **验收**：重新生成不重建整列表；分支上下文完整。

## CHAT-11 文件上传能力矩阵
- **用户故事**：把 PDF/Word/PPT 丢进对话让 AI 总结问答。
- **功能描述**：白名单 v1：pdf/docx/xlsx/pptx/csv/md/txt/图片/音频；单文件 ≤50MB；走 RAG 管线分段索引。
- **交互要点**：解析进度与页数展示；引用标注「xx 文档第 n 页」。
- **验收**：200 页 PDF 定位准确；不支持格式给转 PDF 建议。

## CHAT-12 角色智能体（合规前置）
- **用户故事**：创建固定人设角色反复使用。
- **功能描述**：角色卡=人设 Prompt+开场白+推荐指令+知识绑定。
- **合规红线**（对标豆包 2026-07 拟人智能体新规下架事件）：不做真人拟人陪伴定位；无未成年人默认入口；人设声明「AI 生成」标识常驻；情感依赖场景提示词干预。详见 07 合规章节。
- **验收**：合规审查清单全项通过后方可上线。

## CHAT-13 会话管理增强
