## A · 图像与视频

### TOOL-01 图像生成
- **用户故事**：输入描述生成图片，圈选区域重绘，垫图保持主体一致。
- **功能描述**：T2I/I2I/局部重绘三模式；参考一致性（多参考图）；模型适配 Seedream、通义万相、Flux、SD 系列 API。
- **交互要点**：Konva 蒙版画笔（羽化/粗细）；提示词历史下拉；四宫格候选点选放大。
- **代码映射**：新增页面；蒙版用 `react-konva`。
- **验收**：1024×1024 出图 ≤15s（厂商正常时延）；蒙版边缘无明显锯齿。

### TOOL-02 视频生成
T2V/I2V；Seedance/Kling/即梦适配；异步任务卡+队列进度；单条 ≤10s 成片。P1。

### TOOL-03 分身视频【边界声明】
真人分身需授权验证链路且涉深度合成合规审查——列为 P2 远期，上线前须通过法务合规清单（07 §3）。

### TOOL-04 批量生产与多尺寸适配
- **用户故事**：一个 Prompt 出 N 张候选，并一键适配各平台尺寸。
- **功能描述**：批量数 1–8；预设尺寸组：小红书 3:4 / 抖音 9:16 / B站 16:9 / 公众号 900px；批量导出命名规则 `{prompt_slug}_{size}_{seq}`。
- **验收**：8 张批量任务可取消单个；导出 zip 结构符合命名规则。

### TOOL-05 生成历史与参数回溯
- **用户故事**：三天前的出图效果不错，我要用同样参数改个词再跑。
- **功能描述**：每次生成保存完整参数快照；历史网格视图；「从图片恢复参数」（读取产物元数据）；版本对比滑杆。
- **验收**：任意历史记录一键复现相同输出（同 seed）；元数据丢失时降级为手动参数。

## B · 文档

### TOOL-06 AI 写作
- **用户故事**：给我一个主题和大纲，AI 按我的风格写出长文。
- **功能描述**：多体裁模板（小红书文案/公众号/测评/脚本）；AI 续写/改写/扩写/缩写；**个人风格库**（从历史作品学习偏好，资产飞轮入口）。
- **交互要点**：TipTap 富文本编辑器，Markdown 为源格式；选中段落浮动 AI 菜单；字数统计与平台限制提示。
- **选型说明**：写作编辑器=TipTap；Word 交付物渲染=Univer Docs（TASK-17），以 Markdown/docx 中间格式互通。详见 09 §4。
- **验收**：5000 字长文续写不丢上下文；风格库启用后文风一致性盲测可辨。

### TOOL-07 PPT 生成
- **用户故事**：一句话主题生成可二次编辑的演示文稿。
- **功能描述**：LLM→结构化 slide schema→Univer Slides 渲染→pptxgenjs 导出 .pptx；模板主题包 v1 提供 5 套。
- **交互要点**：大纲先行确认再逐页生成（省 token 且可控）；单页重新生成。
- **风险**：Univer Slides 不达预期则降级 pptxgenjs 直生成+只读预览（08 风险 R2）。
- **验收**：10 页 PPT 全程 ≤3min；导出文件 PowerPoint/WPS 可开。

### TOOL-08 AI 表格
- **用户故事**：上传 Excel 说一句话完成分析出图表。
- **功能描述**：Univer Sheets 渲染编辑；自然语言→公式/透视表/图表；导入 xlsx/csv；导出 xlsx/csv/PNG 图表。
- **边界声明**：MVP 仅文件导入+对话生成，不做数据库直连与网页抓取。
- **验收**：10 万行级打开流畅；公式结果与 Excel 一致性抽检 ≥99%。

### TOOL-09 深入研究
- **用户故事**：给课题自动拆解检索路径，交叉验证后产出带引用的结构化报告。
- **功能描述**：档位选择：快速(3源)/标准(8源)/深入(15+源)；每档展示**预估 token 成本**（BYOK 真金白银）；检索→抓取→去重→交叉验证→报告（Markdown/Typst 排版 PDF）；引用溯源列表。
- **交互要点**：执行中显示检索路径树；报告大纲可中断调整。
- **依赖**：搜索连接器（CHAT-03 同栈）+ rag-pipeline 抓取。
- **验收**：标准档产出 ≤5min；每条结论均可回跳来源原文。

## C · 音频

### TOOL-10 音乐生成
文生曲（TTM）：风格/时长/情绪参数；Suno 类厂商 API 适配；成品入画廊可设为播客 BGM。P2。

### TOOL-11 录音转写
- **用户故事**：一小时的会议录音，转成带说话人分离的纪要。
- **功能描述**：文件/麦克风录音两入口；ASR BYOK（Whisper API/FunASR 等）；说话人分离；输出纪要（概要/待办/时间戳）。
- **下游闭环**：纪要一键流转至 AI 表格（待办清单）或 PPT（汇报页）。
- **验收**：60 分钟音频转写 ≤10min（厂商正常时延）；双人对话分离准确率抽检 ≥90%。

### TOOL-12 播客工坊
- **用户故事**：给一个选题，生成双人对谈播客成品 MP3。
- **功能描述**：全链路=选题大纲(LLM)→对谈脚本(角色 A/B)→多音色 TTS 合成（CosyVoice/ElevenLabs/MiniMax BYOK）→波形剪辑（wavesurfer.js：裁剪/拼接/BGM 混音）→ffmpeg 合成导出 MP3→元信息/RSS 输出。
- **交互要点**：脚本可逐句改写并局部重配音色；波形区标记段落。
- **上游打通**：录音转写（TOOL-11）产物可作为素材注入脚本生成。
- **验收**：10 分钟双人对谈全程 ≤30min（含人工微调）；BGM 混音不压人声。

## D · 媒体处理（ffmpeg sidecar）

### TOOL-13 视频转 GIF
帧率/分辨率/循环参数；调色板算法保画质；时长截取；输出体积预估。验收：10s 720p→GIF ≤30s；体积预估误差 ±20% 内。

### TOOL-14 图片压缩
批量；WebP/AVIF/JPEG 格式转换；质量滑杆+前后对比预览；目标体积模式（"压到 2MB 内"）。编码器选型论证见 09 §6。验收：50 张批量 ≤2min；目标体积模式成功率 ≥95%。

### TOOL-15 视频转码
容器转换 MOV→MP4；H.264/H.265/AV1 可选；**平台预设一键适配**（小红书/抖音/B站：分辨率+码率+封装 profile 库）；音频提取。验收：主流手机素材转码后各平台上传无告警。

> 三件套共用 SQLite 任务队列与 WS 进度推送；产物 `source=tool` 入画廊；画廊 Asset 右键菜单提供快捷入口（PLAT-06）。

## E · 教育

### TOOL-16 解题答疑
拍照识题→OCR→分步讲解（KaTeX 公式渲染已有）；学科覆盖数学/物理/化学为主。
**边界声明**：只做拍照解题+讲解，不做错题本、学情追踪等教育闭环。P2 / M3。
