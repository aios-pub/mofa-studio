# 05 创作工作流（Creation Workflow · FLOW 域）

> 对标 ComfyUI 全量能力，基于现有 @xyflow/react 编辑器（10 种逻辑节点）扩展为 AI 生成产线。定位差异：ComfyUI 面向极客，本产品把工作流低门槛化——专家搭流程，普通用户用 App Mode 填参数。

## FLOW-01 节点画布扩展
- **用户故事**：我拖拽节点连线搭出「底稿→重绘→放大→换背景」的生成管线。
- **功能描述**：扩展现有 xyflow 编辑器：节点分组面板/框选批量操作/小地图/连线类型校验；执行状态实时着色（排队/运行/命中缓存/完成/失败）。
- **代码映射**：`src/pages/workflow/nodes/`（现有 10 种逻辑节点保留，新增生成类）。
- **性能预算**：200 节点画布交互 60fps（07 NFR）。
- **验收**：50 节点工作流搭建无卡顿；错误连线即时标红阻断。

## FLOW-02 生成类节点库
| 类别 | 节点 |
|------|------|
| 输入 | 文本提示词 / 图片上传 / 参考图 / 参数常量 |
| 模型 | API 模型加载（图像/视频/音频厂商+模型选择）/ 本地 Ollama 模型 |
| 生成 | 图像生成 / 图像编辑(I2I) / 视频生成 / 音频 TTS / LLM 文本 |
| 后处理 | 放大 / 抠图(BiRefNet 类) / 格式转换 / 裁剪 |
| 控制 | 条件分支 / 批量展开(队列 N 组参数) / 循环 / 变量传递 |
| 输出 | 预览 / 保存至画廊(source=flow) |

验收：核心 5 节点即可搭出完整文生图链路（对标 ComfyUI 核心五件套心智）。

## FLOW-03 本地推理节点接入
Ollama/LM Studio 存活探测（PLAT 桌面壳已有探测能力）；本地模型作为 LLM 文本节点后端；显存检测与降级提示。

## FLOW-04 执行队列与增量缓存（引擎核心）
- **用户故事**：改了最后一个节点参数，前面的昂贵步骤不要重跑。
- **功能描述**：拓扑调度执行；**签名缓存增量执行**——仅重跑变更节点及其下游（对标 ComfyUI 缓存策略）；多任务队列管理（排队/暂停/取消/优先级）；执行历史与产物回看。
- **实现落点**：Rust flow-engine crate（09 §3）。
- **验收**：20 节点链路仅末节点变更时，重执行时间 <5% 全量耗时。

## FLOW-05 模型管理中心
- **用户故事**：模板缺模型时一键下载到位。
- **功能描述**：云端 API 模型（BYOK 配置即用）与本地模型双轨；本地模型从 HuggingFace/魔搭导入（断点续传）；磁盘占用统计与清理。
- **边界声明**：本期不做本地 GPU 推理运行时，本地推理经 Ollama 等外部服务代理。

## FLOW-06 工作流 JSON 与元数据恢复
导入导出 JSON（可分享复现）；**从输出图片元数据恢复工作流**（生成时嵌入 workflow 快照）；版本历史。

## FLOW-07 模板市场
- 官方内置模板 v1 ≥10 个（文生图/重绘放大/批量出图/文生视频等）；加载时自动检测缺失依赖并引导下载（联动 FLOW-05）；UGC 模板走灵感广场发布流。

## FLOW-08 App Mode
- **用户故事**：我把调好的工作流发布成一个只有 3 个输入框的简单工具给队友用。
- **功能描述**：任意子图封装为 App 表单（暴露选定输入/参数）；生成的 App 出现在创作页工具列表；与「能力双入口」体系打通。
- **价值**：专家搭流程、普通用户填参数——本产品对 ComfyUI 的核心降门槛改造。P2 / M3。

## FLOW-09 ComfyUI 桥接模式【边界声明】
- **用户故事**：我机器上已装 ComfyUI，希望复用它跑本地 SD 工作流。
- **规格**：检测本机 ComfyUI 服务（PLAT 探测）；桥接=**整图委托执行**——将画布导出为兼容 JSON 提交其 `/prompt` API，WebSocket 回收进度与产物入画廊。
- **硬边界（冲突裁决）**：MVP 不支持自建 API 节点与 ComfyUI latent 节点跨引擎混搭——两套类型系统不互连；统一适配层为远期演进项。

## FLOW-10 自定义节点 SDK · 阶段一外置 HTTP 服务
第三方以独立进程提供节点（HTTP 协议：schema 声明+执行端点），画布动态加载注册；沙箱外运行由用户显式信任安装。P2 / M3。

## FLOW-11 WASM 插件沙箱（阶段二）
extism(wasmtime) 运行用户插件节点：安全隔离、多语言编写、能力最小授权（文件/网络白名单）。生态扩展终极形态。P2 / M4。
