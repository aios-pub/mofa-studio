# 07 非功能需求（Non-Functional Requirements）

## 1. 性能预算

| 指标 | 目标 |
|------|------|
| 应用冷启动 | ≤3s（到可交互） |
| 对话首 token 展示 | ≤2s（网络正常，不含模型首字时延） |
| 工作流画布 | 200 节点交互 60fps |
| 内存基线 | 常态 ≤500MB（不含本地推理外部进程） |
| 安装包体积 | macOS universal ≤150MB / Windows ≤180MB（ffmpeg 内置计内） |
| 批量任务 | 50 张图片压缩 ≤2min；不阻塞 UI 线程 |

## 2. 隐私与安全

### 2.1 密钥安全
密钥仅存 OS 钥匙串；渲染层零明文（PLAT-04 硬约束）；日志全量脱敏。

### 2.2 记忆四权能
记忆系统（TASK-19）必须满足：**可见 / 可编辑 / 可删除 / 总开关**。缺失任一项不得上线——这是本地优先承诺的组成部分。

### 2.3 Prompt 注入防护
- 连接器读取的外部内容（邮件/网页/文档）注入 LLM 前打隔离标记（untrusted context 分区）
- 外部内容触发的工具调用需二次确认策略：读类白名单放行、写类/外发类必须用户确认
- 系统指令与用户内容分区拼接，禁止外部内容覆盖系统角色定义

### 2.4 遥测、崩溃与反馈
- 匿名使用统计**默认关闭**，开启须显式 opt-in 并展示采集清单
- 崩溃报告默认开启但仅含堆栈与环境信息，不含用户数据
- 应用内反馈入口（截图标注 + 日志附件可选）

## 3. 合规

### 3.1 AI 生成内容标识
- 图片：EXIF/XMP 元数据写入 AI 生成声明；导出平台预设时保留
- 视频/音频：容器元数据标识；发布指引提示各平台主动声明要求

### 3.2 拟人智能体合规红线（对标豆包 2026-07 下架事件）
角色智能体（CHAT-12）设计约束：
- 不做真人拟人陪伴定位，角色卡强制「AI 生成」常驻标识
- 无未成年人默认入口；情感依赖话术触发干预提示
- 上线前通过内部合规审查清单（法务确认后放行）

### 3.3 内容安全钩子
生成链路预留敏感词过滤中间件挂载点（厂商侧审核之外的应用层兜底）；分身视频等深度合成功能上线前专项合规评估（TOOL-03 边界声明）。

## 4. 可靠性

- SSE 断流自动重连一次 + 手动重试；生成任务失败保留现场可续跑
- 自动化流水线断点续跑依赖 SQLite WAL + 事件溯源（TASK-05）
- 数据库损坏自动检测并从最近备份提示恢复

## 5. 更新策略
tauri-plugin-updater；灰度发布（按比例放量）；更新签名校验；失败回滚上一版本预案。

## 6. 国际化
zh-CN / en-US 双语全覆盖（i18next 已有基建）；新 UI 字符串必须双语文案同步提交（AGENTS.md 约束）；目标市场以国内为主，搜索 API 等区域敏感组件全部可配置切换。

## 7. 兼容性
macOS 13+（Apple Silicon 优先，universal 出包）；Windows 10+ x64（兼容 ARM64 视需求）；最低 8GB 内存设备可用（本地推理除外）。

## 8. 可访问性与体验底线
键盘可达核心流程；主题系统沿用现有 dark/light + 6 色预设 + 字号调节；动效尊重系统减弱动态设置。
