# 08 路线图（Roadmap）

> 全量功能按四期交付；每里程碑含量化验收指标。路由引擎分版本：M1 交付 v1（意图分类+能力预选），M3 交付 v2 完整四层。

## M1 · 对话创作闭环（约 6 周）

**主题**：装上就能用——BYOK 底座 + 助理模式 + 首批创作工具。

| 范围 | 需求 ID |
|------|---------|
| 平台底座 | PLAT-01~08（内嵌后端/网关/密钥/配额/Asset 模型/SQLite/账号决策）、PLAT-13 导航、PLAT-14 专家模式 |
| Onboarding | ONBOARD-01~03 |
| 对话底座 | CHAT-01/02/04/05/09/10 |
| 创作工具 | TOOL-01 图像生成、TOOL-04 批量多尺寸、TOOL-06 AI 写作 |
| 可观测 | PLAT-15 Span 数据层 |

**量化验收指标**
- 新用户安装 → 配置 Key → 首次成功生图 **≤10 分钟**
- 冷启动 ≤3s；首 token ≤2s
- 专家模式开启后存量 B 端功能 100% 可达
- 内嵌后端通过全部 OpenAPI 契约测试

## M2 · 创作全量 + 工作流 MVP（约 8 周）

| 范围 | 需求 ID |
|------|---------|
| 对话增强 | CHAT-03/06/08/11/13 |
| 创作工具 | TOOL-02/05/07/08/09/10/11/12 + 媒体三件套 TOOL-13/14/15 |
| 工作流 MVP | FLOW-01~07（画布/节点库/队列增量缓存/模型中心/JSON/模板市场） |
| 资产飞轮启动 | TASK-21 灵感广场（做同款+缺依赖检测） |
| 可观测 | PLAT-15 用户面板「用量与日志」 |
| 其他 | PLAT-03 分层路由、PLAT-09 存储管理、ONBOARD-04 渐进披露 |

**量化验收指标**
- 灵感做同款 → 首个成果 ≤5 分钟；缺依赖引导安装成功率 ≥80%
- 增量执行：末节点变更重跑 <5% 全量耗时
- 播客工坊 10 分钟双人对谈全程 ≤30 分钟

## 风险登记册

| ID | 风险 | 影响 | 缓解方案 |
|----|------|------|---------|
| R1 | WASM 节点 SDK 成本高 | FLOW-11 延期 | 已推至 M4，阶段一外置 HTTP 服务兜底 |
| R2 | Univer Slides 成熟度不足 | PPT 编辑体验受限 | Plan B：pptxgenjs 直接生成 + 只读渲染降级（Sheets/Docs 不受影响） |
| R3 | ffmpeg 打包体积 ~70MB | 安装包超标 | macOS/Windows 主渠道内置，低配渠道按需下载 |
| R4 | Univer 学习曲线 | 表格/文档开发进度 | 封装独立组件渐进接入，先行 Sheets 后 Docs/Slides |
| R5 | 拟人智能体合规变化 | 角色智能体下架风险 | 合规前置设计（07 §3.2），P2 低排期可随时冻结 |
| R6 | 自研 agent-runtime 复杂度 | M3 进度风险 | AgentScope 抽象借鉴 + 单 Agent 先行保底（三分法默认策略不依赖专家团） |
| R7 | 存量 mock→real 迁移工作量 | 主线被拖累 | API 域处置清单（06 附录）分批切换，专家模式域冻结 |
